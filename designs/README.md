# Designs

Drop Figma frame screenshots here, named after the screen they cover (e.g. `01-signup.png`,
`04-active-session.png`). When a screen has a matching file here, match its layout, colors, and
type closely. Screens with no file yet fall back to the default look described in CLAUDE.md
(dark theme, pink/orange accents, 430px phone-width container, 60px+ tap targets).
